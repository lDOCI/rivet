# Rivet — роадмап

Сенсорный интерфейс для Klipper/Moonraker на Rust + Slint.
Первая цель — Flashforge Adventurer 5M / 5M Pro на [KlipperMod](https://github.com/xblax/flashforge_ad5m_klipper_mod).

Этот файл — **единственный источник правды** о том, что делаем и в каком порядке.
Техника — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), принятые решения — в [docs/DECISIONS.md](docs/DECISIONS.md).

---

## Как работаем с этим документом

1. Работаем строго по текущей вехе. Задачи из следующих вех не берём, пока не закрыт **критерий готовности** текущей.
2. Задача сделана, когда она в `main` и CI зелёный. Тогда ставим `[x]`.
3. Нашли новую работу — добавляем задачу в нужную веху. Если она больше дня или ломает порядок вех, это изменение плана (п. 4).
4. Изменение плана: правим этот файл и пишем строку в «Журнал изменений» внизу. Если меняется архитектура или принцип — запись в `docs/DECISIONS.md`.
5. Сроков в датах нет. Есть оценка: **S** ≤ 1 вечер, **M** 2–4 вечера, **L** неделя+. Если задача выросла из своей оценки — повод остановиться и пересмотреть.

Статусы вех: ⬜ не начата · 🟨 в работе · ✅ закрыта.

Задачи: `[ ]` не сделано · `[~]` сделано в ветке `m1/pilot-1to1` и проверено на Mac (снимки, тесты), ждёт проверки на принтере и merge в `main` · `[x]` в `main`.

### Git

- `main` всегда собирается и проходит CI. Прямо в `main` пушим только мелочи (опечатки, документация).
- Задача = ветка `m1/files-screen` → PR → самопроверка + CI → squash merge.
- Коммиты в стиле Conventional Commits: `feat(ui): ...`, `fix(moonraker): ...`, `docs: ...`, `chore: ...`.
- Релизы — теги `v0.1.0-alpha` и т.д., артефакты собирает CI.

## Принципы (решают споры)

1. **Не мешать печати.** Экран никогда не должен стать причиной сбоя: ни по памяти, ни по CPU. Любая фича, нарушающая бюджет, выключается или не делается.
2. **Бюджет памяти — это фича.** 128 МБ на всё: Klipper, Moonraker и мы. Мы самый лёгкий экран на этом железе, и это главное отличие.
3. **AD5M first, но экран для любого Klipper.** AD5M проверяем первым и глубже всех, а функции включаются по тому, что реально есть в конфиге (нет датчика или макроса — нет экрана).
4. **1–2 тапа.** Частые действия доступны с главного экрана. Необратимые действия подтверждаются; исключение — аварийная остановка, она в одно касание.
5. **Честное состояние.** Не показываем устаревшие данные: если Klipper не готов или нет связи, значения скрываются, кнопки блокируются.
6. **Сначала Mac, потом принтер.** Любая фича сначала работает против мока и реального Moonraker по сети.

## Не делаем (осознанно)

- Поддержку OctoPrint и прошивок без Moonraker.
- Веб-интерфейс: для этого есть Mainsail и Fluidd.
- Базу «100+ принтеров» с автоопределением.
- Систему плагинов до 1.0. (Темы — набор цветов акцента и фона — сделаны раньше по просьбе владельца.)
- 3D-превью G-code на устройстве со 128 МБ (возможно в remote-режиме после 1.0).
- Свой установщик для Z-Mod (ZMOD): у Z-Mod свой выбор экрана, его разработчик встраивает Rivet сам по [docs/integration.md](docs/integration.md).

## Цели по ресурсам (проверяем на AD5M, release-сборка)

| Метрика | Цель | Потолок |
|---|---|---|
| RSS в простое | ≤ 10 МБ | 15 МБ |
| RSS в пике | ≤ 20 МБ | 25 МБ |
| CPU в простое | ~0 % | 1 % |
| CPU во время печати | ≤ 5 % | 10 % |
| Размер бинаря | ≤ 8 МБ | 16 МБ |

Сейчас бинарь 14.1 МБ — выше потолка (было 16.7 МБ до общего тела форм). Замер на принтере показал, что RSS это не раздувает (10–12 МБ в простое): код подгружается страницами по мере обращения. Потолок размера пересматриваем в M2.
| Старт до первого кадра | ≤ 1.5 с | 3 с |

## Открытые вопросы

- Памяти мало: на AD5M Pro свободно 38 МБ при работающих Klipper, Moonraker и стоковом экране (Moonraker сам 43 МБ). Бюджет Rivet ≤ 20 МБ проверяем на устройстве в первую очередь — M0.

- ~~Формат framebuffer на AD5M~~ — `Bgrx8888`, 800×480, поворот не нужен.
- ~~Тач-контроллер~~ — `ts_uinput` отдаёт оси 0–799 и 0–479, как у экрана; поворот не нужен.
- Как KlipperMod выбирает вариант GUI при старте — нужно для установщика (M2).
- Чем на AD5M управляются яркость подсветки и поворот экрана — для настроек экрана (M2).
