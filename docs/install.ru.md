# Установка, обновление, удаление

Для Flashforge Adventurer 5M / 5M Pro с [Klipper Mod](https://github.com/xblax/flashforge_ad5m_klipper_mod).
[English version](install.md).

На **Z-Mod** Rivet ставит сам Z-Mod, когда добавит его в список своих экранов (как HelixScreen);
описанные здесь установщики там отказываются работать. **Forge-X** и стоковая прошивка не
поддерживаются.

## С флешки

Так же ставится и обновляется сам Klipper Mod.

1. Скачайте `rivet-<версия>-usb.zip` из [последнего релиза](https://github.com/lDOCI/rivet/releases/latest).
2. Распакуйте на флешку, отформатированную в FAT32. В корне флешки должны лежать
   `flashforge_init.sh` и папка `rivet`. Остальное с флешки убирать не нужно.
3. Выключите принтер, вставьте флешку, включите.
4. Klipper Mod видит `flashforge_init.sh` и передаёт его стартовому скрипту принтера, который его
   запускает. На экране «Устанавливаю Rivet…» (около минуты), потом «Rivet установлен — выньте
   флешку».
5. Выньте флешку. Принтер перезагрузится в Klipper Mod уже с Rivet.

Если что-то помешало установке, экран напишет «Rivet не установлен», а причина будет в
`rivet-install.log` на флешке. На принтере ничего не изменилось, если в логе нет слов «partly
installed» (тогда запустите флешку ещё раз или удалите Rivet флешкой удаления). Выньте флешку —
принтер запустится как раньше.

Если экран так и не показал результат, выньте флешку и выключите-включите принтер: без флешки
Klipper Mod запускается как обычно.

**Удалить Rivet** — так же, архивом `rivet-<версия>-usb-remove.zip`: экран напишет «Rivet удалён»,
и после перезагрузки вернётся GuppyScreen (или тот экран, который Rivet заменил).

## По ssh с компьютера

Для тех, кто собирает Rivet сам или привык к терминалу. Нужен доступ по ssh под `root` (так в
Klipper Mod по умолчанию). Из распакованного `rivet-<версия>-installer.tar.gz` или из исходников
после `cargo printer`:

```bash
tools/install.sh IP_ПРИНТЕРА           # установить или обновить
tools/install.sh --dry-run IP_ПРИНТЕРА # только рассказать, что сделает
tools/uninstall.sh IP_ПРИНТЕРА         # удалить всё, вернуть старый экран
tools/uninstall.sh --keep-config IP_ПРИНТЕРА
```

`install.sh` отказывается, пока идёт или стоит на паузе печать, и если экран держит неизвестная
программа; `--force` отменяет обе проверки. `--keep-config` сохраняет настройки и калибровку тача
для следующей установки. Файлы передаются через `ssh … cat`: в Klipper Mod нет sftp-сервера,
поэтому `scp` не работает.

`tools/swap-screen.sh rivet IP_ПРИНТЕРА` запускает Rivet из `/tmp` до следующей перезагрузки,
ничего не устанавливая; `tools/swap-screen.sh guppy IP_ПРИНТЕРА` возвращает Guppy.

## Что меняется на принтере

| Путь | Что |
|---|---|
| `/opt/rivet/rivet` | программа |
| `/opt/rivet/rivet.sha256`, `release_info.json` | её контрольная сумма и версия, для обновлений |
| `/opt/rivet/rivet.good` | копия последней версии, проработавшей 30 секунд, — чтобы было куда вернуться |
| `/opt/rivet/replaced` | какой экран выключен и работал ли он |
| `/etc/init.d/S80rivet` | запускает Rivet при старте и следит, чтобы он работал |
| `/etc/init.d/_S80guppyscreen` | стартовый скрипт старого экрана, переименован, чтобы не запускался |
| `/root/printer_data/config/moonraker.conf` | добавляется секция `[update_manager rivet]` (копия файла до изменения — `moonraker.conf.before-rivet`) |
| `/root/printer_data/config/rivet.toml` | файл настроек, создаётся, только если его нет ([пример](rivet.toml.example)) |
| `/root/printer_data/config/rivet-touch.json` | калибровка тача, после того как вы её пройдёте |
| `/root/printer_data/logs/rivet.log`, `rivet-console.log` | лог и записи о падениях и перезапусках |
| база Moonraker, раздел `rivet` | настройки, изменённые на экране: тема, яркость, сон, блокировка, пресеты… |

Больше ничего не трогается. Удаление убирает всё это и переименовывает скрипт старого экрана
обратно. Удаление с флешки не может достучаться до базы Moonraker (в этот момент он не запущен) и
оставляет раздел `rivet`: без Rivet он ничего не делает, а при повторной установке вернёт ваши
настройки. `tools/uninstall.sh` удаляет и его.

## Обновления

Moonraker проверяет новые релизы на GitHub, как делает это для Fluidd и Mainsail. Обновить:

- на экране: **Настройки › Обновления**. В строке Rivet написано, есть ли новая версия, а
  **«Обновить экран»** её ставит; экран перезапустится сам;
- или в Fluidd/Mainsail, в списке обновлений (*rivet*).

Во время печати Moonraker обновления не делает.

Новая версия запускается под присмотром (`S80rivet`):

- версия, не совпавшая с контрольной суммой, не запускается;
- версия, которая дважды завершилась в первые 30 секунд, заменяется последней версией,
  проработавшей 30 секунд;
- в обоих случаях в Настройки › Обновления будет написано «новая версия не запустилась,
  вернулась прежняя».

Если Rivet упадёт, он запустится снова через секунду; при повторных быстрых падениях пауза
растёт (до минуты), чтобы цикл падений не грузил процессор.

## Логи

В Fluidd или Mainsail, рядом с `klipper.log`: `rivet.log` (что делал Rivet) и `rivet-console.log`
(падения, перезапуски, откаты). На принтере:

```bash
/etc/init.d/S80rivet stop | start | restart
tail -f /root/printer_data/logs/rivet.log
```

Подробнее: `log_level = "debug"` в `rivet.toml`, затем перезапустить экран.

## Если касания мажут

Настройки › Экран › **Калибровка тача**: коснитесь девяти крестиков тем пальцем, которым обычно
нажимаете. **Тест касаний** (там же) показывает, куда вы попадаете. Калибровка хранится в
`rivet-touch.json`; удалите файл, чтобы вернуться к калибровке самой панели.
