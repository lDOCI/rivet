# UX audit, 2026-11-08

All 67 screens rendered at 800×480 with the real canvas runtime and reviewed one by one
against `design-code.md`. Fixed in the same pass unless marked open.

## System-wide
- Secondary actions were huge centred slabs → now left-aligned rows with an arrow; only the one primary action is a filled button.
- Exact numbers had ± only → tapping the value opens a numeric keypad (with ± for negative ranges) on every stepper.
- Hub tiles truncated captions («сопло в…», «оси, парковка, м…») → value tiles show one label, tool tiles wrap to two lines.
- Heating arc could not be dragged: the centre label sat on top of the arc and ate touches → `pointer-events: none`.
- Macros and Console had the same terminal icon → Macros uses a lightning bolt.

## Per screen
- Печать: invented «Печать стенок» → «Печатается»; «Стоп» clashed with the rail E-stop → «Отменить».
- Подстройка, Скорость и поток: speed and flow at 100% showed different bar heights → same 50–200% scale; «Pressure advance» wrapped → «PA».
- Пауза на слое: two competing primaries → layer stepper + one «Поставить паузу».
- Пропуск объектов: objects had no names → names inside shapes.
- Печать завершена: looked like a settings list → hero with thumbnail, time, plastic, «Печатать снова».
- Закончился филамент: five equal buttons → numbered steps 1-2-3 and one «Продолжить печать».
- Блокировка: «СТОП работает и здесь» → proper E-stop control.
- Файл: «Нужен PETG — проверьте…» while PETG is loaded → green «PETG — как раз заправлен».
- Действия с файлом: accent on «В очередь», USB copy shown for a printer file → plain rows.
- Очередь: «Очередь готова» meant nothing → numbered jobs, «Начать очередь», wait-between-prints switch.
- Пресеты нагрева: eight stepper rows → one card per material, nozzle and bed side by side.
- График: axis labels did not match the data → 200/140/80/20°.
- Движение: «Моторы выкл.» wrapped with an icon → one line. «Движение · ещё»: parking buttons coloured as primary → rows.
- Экструдер: buttons said «25 мм» whatever length was picked → «Выдавить / Втянуть».
- Сушка: an info row used as a sentence → removed.
- Свет: four bars squeezed the switches into 3-line labels → brightness only (RGB bars only for RGB strips).
- Устройства: beeper as a range bar → switch.
- Z-offset: five-line paragraph → two lines. Мастер бумагой: steps as right-aligned «values» → height readout, step picker, big ↑/↓.
- Вибрации: four stacked buttons → axis picker + one «Измерить».
- PID: fan as a full-height bar → 3-way choice.
- TMC: lone current stepper for one motor → removed.
- Экран: sleep options wrapped («5 / мин») → unit in the title.
- Блокировка и PIN: «Стоп работает всегда» row → removed. Безопасность: wrapped label shortened.
- Обновления: developer note on screen → removed.
- Ошибка Klipper: «Журнал» opened Settings → opens Console.
- Катушки: active spool listed twice → once, marked.

## Open
- Обслуживание: counters as text; progress bars would read faster.
- Камера: timelapse settings shown even without a camera.
- Винты стола: a bed diagram would beat a list.
- Макросы: macros without parameters should run from the list (with confirm), not open a form.
