# Каталог экранов (до беты — все)

67 экранов прототипа + боковое меню. Источник: [холст прототипа](https://claude.ai/artifact/PnGxUHsDknJNEPP3s68usB), `docs/ux/style/*.dc.html`.
Данные каждого экрана — в [data-sources.md](data-sources.md); функции эталонных экранов — в [feature-inventory.md](feature-inventory.md).
Правило (D-011): всё в этом списке делаем до беты; на конкретном принтере экран или строка появляются, только если Klipper/Moonraker сообщает нужный объект.
Статус «готов 1:1» ставит только агент-сверщик ([team/ROLES.md](../team/ROLES.md)), когда попиксельная сверка проходит.
