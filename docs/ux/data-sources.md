## Hand-drawn screens

| Screen | Item | Source |
|---|---|---|
| Главная | nozzle / bed temperature | `extruder.temperature`, `heater_bed.temperature` (+ `.target`) |
| Главная | last print, duration | `server.history.list limit=1` |
| Главная | loaded material | Rivet store (set by the load wizard) or Spoolman active spool |
| Главная | file counts | `server.files.list` (root `gcodes`, USB mount) |
| Печать | progress, file | `virtual_sdcard.progress`, `print_stats.filename` |
| Печать | time left, finish at | estimate from `print_stats.print_duration` and file `estimated_time` |
| Печать | layer N of M | `print_stats.info.current_layer/total_layer` (needs `SET_PRINT_STATS_INFO` from slicer) |
| Пропуск объектов | objects, excluded | `exclude_object.objects`, `exclude_object.excluded_objects` |
| Файл | time, filament, layers, nozzle, thumbnail | `server.files.metadata` (`estimated_time`, `filament_weight_total`, `filament_type`, `layer_count`, `nozzle_diameter`, `thumbnails`) |
| Файл | nozzle matches | metadata `nozzle_diameter` vs `configfile.settings.extruder.nozzle_diameter` |
| Нагрев | max on arc / keypad | `configfile.settings.<heater>.max_temp` |
| Нагрев | time to target | Rivet estimate from the temperature slope |
| Движение | position, limits | `toolhead.position`, `toolhead.axis_minimum/axis_maximum`, `toolhead.homed_axes` |
| Z-offset | value | `gcode_move.homing_origin[2]`; save = `Z_OFFSET_APPLY_PROBE` + `SAVE_CONFIG` |
| Карта стола | grid, range, profile | `bed_mesh.probed_matrix`, `bed_mesh.profile_name`, `bed_mesh.profiles` |
| Загрузка филамента | temperatures | Rivet heat presets (Moonraker database) |
| Загрузка филамента | max extrude | `configfile.settings.extruder.max_extrude_only_distance` |
| Сообщения | entries | Rivet log of Klipper events, `notify_gcode_response`, print state changes |
| Принтер остановлен | message | `printer.info.state_message` |
| Нет связи | retry counter | Rivet client reconnect backoff |
